# DexLink assets

Only project-authored procedural geometry, scene fixtures, and the explicitly
documented XHand package belong here. XHand was sourced from DexMachina under
MIT; its exact source commit and the DexLink-derived variants are documented in
`robots/xhand/NOTICE.md`.

Dataset-derived meshes, MANO files, other robot-vendor descriptions, and
third-party CAD models belong under ignored `external_data/` mount points.
