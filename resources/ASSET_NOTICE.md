# Runtime asset pack

The archive supplies the geometry used by the packaged task catalog and cup
programs, together with project-created SAM3D targets and
ShapeNet alignment metadata. It is installed into ignored local directories,
not included in the source MIT grant as one uniformly licensed dataset.

The tutorial resources include processed OakInk/ShapeNet object geometry.
Provider terms and attribution continue to apply: see [THIRD_PARTY.md](../THIRD_PARTY.md)
and [the dataset guide](../external_data/README.md). Users obtain raw source
motion datasets and MANO model parameters directly from their providers;
those files are not part of this archive. The separately licensed XHand model
is in the source tree with its existing notice and license.

`manifest.json` identifies the archive and each installed file by SHA-256.
The asset ZIP and its checksum are publicly downloadable from the Google Drive
links recorded in the manifest. The selected policy archive is hosted separately;
see [resource setup](../docs/resources.md) for both download commands.
