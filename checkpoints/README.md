# Trained policies

Install the 42 positive checkpoint sets from the
[public Google Drive archive](https://drive.google.com/file/d/15qyIG4-DUaonUXvSKro91IieNQNhp7-5/view?usp=sharing)
using `dexlink-resources checkpoints`. Follow [resource setup](../docs/resources.md).
The task-to-step/file-hash mapping is in `tasks/catalog.json`.

The [checksum file](https://drive.google.com/file/d/1y1XayQjV8_cw5ZhA3vUpaJLsk7_tdAia/view?usp=sharing) accompanies the archive.
